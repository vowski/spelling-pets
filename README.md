# Spelling Pets 🐾

Daily spelling practice for a Year 3 child, covering the National Curriculum spellings for Years 1–4,
with a pet to look after and rewards to earn. Everything is stored on the laptop. There are no accounts, no tracking and no adverts.

## Install on the laptop (one time)
1. Open the app's web address in **Microsoft Edge**.
2. Click **⋯ → Apps → Install this site as an app**.
3. A **Spelling Pets** icon appears on the desktop and Start menu. Use that from now on. It works offline.

## First time
- Set a 4-digit grown-up PIN, then your child picks an egg and names their pet.
- The first few sessions include a **Treasure Hunt**: a gentle check of what they already know. The pet hatches when it's finished.

## Every day (about 10 minutes)
Press **Start today's adventure!** The app chooses review words, new words, a game and a quick check.
After the adventure, **Free Play** unlocks all the games.

## Grown-ups' dashboard (Grown-ups button, bottom of the home screen)
- **Overview**: this week, progress towards Year 3 targets (50 and 70 of the Year 3/4 words), trouble spots with tips.
- **School Standards**: the spelling statements from the school's writing grids, with evidence.
- **School Words**: paste each week's list and set the test date. The day before, the app runs a practice test. **Print practice sheet** gives a Look-Say-Cover-Write-Check page.
- **Rewards**: add real-world rewards (e.g. "5 practice days = trip to the park") and set the weekly goal.
- **Settings**: voice, speed, session length, sounds, dyslexia-friendly font, PIN.
- **Data**: backups, restore and reset.

## Please set up backups
Progress lives in this browser on this laptop. In **Data → Choose a backup folder**, pick a folder for the backups.
A backup is then saved after every session. You can also **Download backup** at any time.
A folder on the laptop keeps everything local. A OneDrive folder also protects against losing the laptop, but it copies her progress to Microsoft's cloud.

## Voices
Edge's "Natural" British voices (e.g. Libby, Sonia) sound best; they send the spoken words to Microsoft's speech service.
Offline voices (Hazel, George, Susan) send nothing. Choose in **Settings → Voice**.
